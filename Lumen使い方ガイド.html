Lumen 使い方ガイド

不動産登録用の写真を、編集 → キャプション → 保存 まで進めるための手順書です。

（アプリ v35 時点 / 2026-09-10）

リポジトリの README.md と、社内Obsidianの「Lumen写真編集ツール」も参照してください。

1. 起動する

どれか1つでOKです。

方法操作
おすすめFinder で 開く.command をダブルクリック
ObsidianからLumen起動.app をクリック
社内サーバーブラウザで社内公開URLを開く
  • 推奨ブラウザ: Google Chrome
  • 黒いターミナルが開いた場合は閉じない（閉じると止まります）
  • 画面左上のバージョン（例: v35）が出ていれば起動成功

つながらないときは → README / Obsidianのトラブルシュート

2. 写真を入れる（写真タブ）

  1. 左の 「写真」 タブを開く
  2. 写真をドラッグ＆ドロップ、またはファイル選択
  3. 複数枚まとめて追加できる

最初に決めておくと楽なこと

項目おすすめ
物件種別マンション / 戸建て / 土地
物件住所任意（周辺コメントの参考になる）
各写真の名前保存ファイル名になる（例: 外観 → 外観.jpg）

HEIC（iPhoneのまま）は Chrome で読めないことがあります。JPEG / PNG を使ってください。

3. 編集する（編集タブ）

左の 「編集」 タブへ。上の小さなタブで機能を切り替えます。

よく使う順番（例）

① サイズ（IRI） → ② 明るさ → ③ 空 → ④ ぼかし → ⑤ 透かしは出力タブ

明るさのあとにぼかしもかけられます（複数編集OK）。

サイズ（IRI登録向け）

プリセットいつ使う目安
物件写真外観・室内・間取など（基本はこちら）400〜800px・250KB以内
見出写真一覧の小さいサムネ用50〜90px・5KB以内
  1. 「物件写真」または「見出写真」を選ぶ
  2. 必要なら「この写真に適用」または一括適用
  3. 保存時も、選んだ上限の近くまで画質を自動調整します

明るさ

  • スライダーで明るさ・コントラストを調整
  • 暗い室内写真は、先に明るくしてからキャプション生成すると精度が上がりやすい

空の編集

薄曇り・白い空を、自然な青空に置き換えます。

  1. 「自然な青空に置き換え」 を押す（いちばん簡単）
  2. 足りないところは 漏れ補修ブラシ → 追加 でなぞる
  3. 塗りすぎたら 消す、またはブラシ範囲をクリア

電線の細い隙間もだいたい検出しますが、残ったらブラシで足してください。

隠す（ぼかし）

やり方使い方
手動「隠す」ブラシでなぞる
自動「人物」「車のナンバー」にチェック → 検知してぼかす
やり直し「ぼかしを元に戻す」／復元ブラシ
  • ナンバーはプレート本体だけを狙います（車体全体にはかけません）
  • Gemini APIキーがあるとナンバー精度が上がります

トリミング・角度

  • 枠を動かして範囲を決め、「適用」
  • 傾きは角度スライダー or 90°回転 →「適用」

4. キャプションを付ける（キャプションタブ）

登録サイトの写真コメント用です。

ルール（重要）

  • 最終出力は 36文字以内
  • 《杏栄》 は 入れる / 入れない を選べる

- 入れる → 本文は最大32文字

- 入れない → 本文のみ最大36文字

手順

  1. 《杏栄》 の有無を決める
  2. 写真ごとに カテゴリを先に選ぶ（例: リビング、外観、現地）
  3. どちらかで本文を作る

- AIで生成（Gemini APIキーが必要）

- 定型文から選ぶ

  1. 必要なら手直し
  2. 「コピー」→ 登録サイトへ貼り付け
  3. まとめて出すときは「全件コピー」や一覧保存

AIがうまくいかないときは定型文が入ります。内容を確認して書き換えてください。

APIキーの取り方 → README の AI（Gemini）節

5. 保存する（出力タブ → 上部の保存）

保存前チェック

  1. 出力 タブで

- 透かし（ロゴ）ON/OFF

- ロゴの位置（四隅）

- 保存フォルダを選ぶ（初回）

- 「同名ファイルを上書き保存」の有無

  1. サイズプリセットが正しいか（物件 / 見出）
  2. 写真名が保存したいファイル名になっているか

保存ボタン

ボタン内容
保存今の1枚をフォルダへ
すべて保存全枚をフォルダへ
ダウンロードブラウザのダウンロードへ（フォルダ未設定時など）

保存後のトーストに、サイズ（KB）と画質段階が出ます。

6. 1件あたりの最短フロー

起動
 → 写真を入れる・名前を付ける
 → 編集: 物件写真サイズ → 明るさ →（必要なら）空・ぼかし
 → キャプション: カテゴリ → 生成 or 定型 → コピー
 → 出力: 透かし確認 → 保存

複数物件を続けるときは、上部の 家アイコン で初期画面に戻すか、物件情報横のゴミ箱で住所・名前・キャプションだけ消してください（写真を残したいとき）。

7. 困ったとき（最短）

困りごとまずやること
画面が古い／おかしい上部「再読み込み」または Cmd+Shift+R
つながらない開く.command または Lumen起動.app を再実行
ぼかしが画面に出ない再読み込み（v34以降で明るさ後の隠す処理もOK）
空が一部残る漏れ補修ブラシで追加
保存が小さい／大きい見出と物件のプリセットを確認
同名で保存できない出力タブの上書きON、または名前を変える
AIが英語／変な文定型文に切り替わるので手直し。キー・カテゴリを確認
